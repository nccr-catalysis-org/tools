List of digital tools built by NCCR Catalysis (under construction)

  • Atom Detection : Tool to detect metal atoms in .tiff microscopy images.
  • Spock : Build volcano plots from experimental catalytic data using systematic piecewise regression.
  • Morfeus : Python package to calculate molecular and atomic stereo-electronic properties from 3D structures. It can also generate conformer ensembles from SMILES.
  • CurryBO : Tool with a web interface and python package to estimate the most general reaction conditions based on given experimental data.
  • Scine : Platform of quantum chemistry tools for the automated exploration of chemical reaction networks.
  • NaviCat : Platform of tools and datasets for digital catalyst discovery, including volcano plot construction (volcanic), microkinetic modeling (mikimo), conformer selection (marc), etc.
  • EquiReact : Geometric deep learning model that predicts reaction properties from the 3D structures of reactants and products.
  • B2R2 Reaction Representation : Generates physics-based reaction representations usable for machine learning.
  • Dataset Explorer : Interactive tool for processing, visualizing, and searching scientific datasets. It helps users inspect dataset contents, generate metadata, and retrieve relevant information through a web interface and semantic-search workflows.
  • MultimodalAnalytical : Framework for molecular-structure prediction from analytical data such as IR and NMR spectra. It supports multimodal foundation-model workflows for structure elucidation from experimental or simulated spectra.
  • rxn-ir-to-structure : Tool for predicting molecular structures directly from infrared spectra. It provides workflows for preparing IR spectral data and training or using models that translate spectra into molecular representations.
  • nmr-to-structure : Model framework for predicting molecular structures from NMR spectra. It includes tools for simulating spectra, preparing datasets, and training transformer-based structure-elucidation models.
  • OChemR : Optical chemical-recognition tool that converts images of chemical reactions into machine-readable reaction representations. It detects molecules, arrows, and text in reaction schemes and converts them into structured chemical data such as SMILES.
  • rxnmapper : Atom-mapping tool for chemical reactions based on transformer attention. It identifies which atoms in the reactants correspond to atoms in the products, enabling mapped reaction SMILES and reaction-mechanism analysis.
  • disconnection_aware_retrosynthesis : Retrosynthesis framework that allows users to guide predictions by specifying desired bond disconnections. It supports interactive retrosynthetic planning where the model proposes routes consistent with a chosen strategic disconnection.
  • biocatalysis-model : Machine-learning model for forward prediction and retrosynthetic planning of enzymatic and biochemical reactions. It uses reaction data enriched with enzyme-class information to make biocatalysis-aware predictions.
  • rxn_yield : Deep-learning tool for predicting chemical reaction yields from reaction representations. It uses transformer-based models to estimate expected yield and study how reaction data quality affects yield prediction.
  • smiles2actions : Model for converting reaction SMILES into structured laboratory action sequences. It predicts procedural steps such as adding reagents, heating, stirring, or purification from a chemical equation.
  • rxnfp : Python library for generating machine-learning fingerprints of chemical reactions. These reaction embeddings can be used for similarity search, clustering, classification, visualization, and reaction-space analysis.
  • sac-action-extraction : Tool for extracting structured synthesis actions from experimental procedures for single-atom catalysts. It converts free-text protocols into machine-readable steps to support dataset creation and automation.
  • sac-finetuning : Repository for fine-tuning language models on single-atom catalyst synthesis procedures. It focuses on generating or standardizing SAC-specific experimental protocols from structured catalyst information.
  • ChemCrow : Agent which augments LLM with expert-designed chemistry tools to solve chemical reasoning tasks.
  • EnzyMS : Automated pipeline for processing LC-MS data from bioacatalysis experiments.
  • racerTS : Python package for rapid conformer sampling of transition-state structures using constrained distance geometry.
  • OntoGen : LLM-based tool to generate ontologies from the literature.
  • PULPO : Framework for life cycle optimization based on life cycle inventories.
  • text2flowsheet : LLM-assisted pipeline that digitizes chemical process descriptions from text into machine-readable flowsheet graphs.
  • Saturn : LLM-based generative model for sample-efficient de novo small molecule design.
  • DeepCV : Deep learning framework for training an autoencoder model on molecular representations to learn collective variables.
